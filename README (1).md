# Simple Interest Calculator

A Bash-based command-line calculator that computes simple interest from user-provided values.

## Formula

Simple Interest (SI) is calculated using:

**SI = (P × R × T) / 100**

Where:
- **P** = Principal amount
- **R** = Rate of interest per year (in percent)
- **T** = Time period in years

## Features

- Accepts principal, rate of interest, and time period from the user.
- Calculates simple interest using the standard formula.
- Displays the calculated simple interest.
- Uses Bash shell scripting and command-line input.

## How to Run

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example

```text
Enter principal amount: 10000
Enter rate of interest (% per year): 5
Enter time period (years): 2

Simple Interest = 1000
```
